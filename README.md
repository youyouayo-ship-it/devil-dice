# Devil Dice

Devil Dice v25 浏览器体验版。

打开游戏网页，输入昵称，点击「新开游戏」即可开始，无需安装或登录。支持手机和桌面浏览器。

## 存档与排行榜

游戏在浏览器中运行；存档、历史最佳和排行榜仅保存在当前浏览器，不会跨设备同步。

音乐在第一次点击后启用，可通过游戏内的声音按钮开关。

## 部署

通过 GitHub Pages 从 main 分支根目录发布。更新根目录的 index.html 即可更新游戏。
